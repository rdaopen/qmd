# Quick Media Downloader

Quick Media Downloader is a modern, feature-rich Windows application for downloading videos and audio from YouTube and other platforms. It is built on top of the powerful [yt-dlp](https://github.com/yt-dlp/yt-dlp) package, ensuring support for a wide range of sites and high-quality downloads.

## Features

- **High Quality Downloads**: Support for 4K, 1080p, and other resolutions. Get the best visual experience.
- **Audio Extraction**: Convert videos to high-quality MP3s (up to 320kbps) with a single click.
- **Playlist Support**: Download entire playlists efficiently. No need to download videos one by one.
- **Modern UI**: Sleek, dark-themed interface built with CustomTkinter for a premium feel.
- **History Tracking**: Keep track of your downloads, play them, or open their location directly.
- **Smart Clipboard**: Right-click to paste URLs instantly from your clipboard for quick access.
